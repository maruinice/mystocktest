# API数据查看功能使用说明

## 📋 功能概述

在API管理页面新增了"查看数据"功能，允许用户直接调用Tushare API并查看返回的实际数据。

## 🎯 功能特性

### ✅ 核心功能
- **一键查看数据**: 点击"查看数据"按钮直接调用API
- **参数配置**: 支持常用查询参数的设置
- **数据展示**: 智能识别数据格式，表格或JSON展示
- **数据导出**: 支持将查询结果导出为CSV文件
- **实时统计**: 显示数据条数、响应时间等信息

### 🔧 支持的参数
系统自动识别并显示以下常用查询参数：
- `ts_code` - 股票代码
- `symbol` - 股票简称
- `trade_date` - 交易日期
- `start_date` - 开始日期
- `end_date` - 结束日期
- `limit` - 数据条数限制
- `offset` - 数据偏移量

## 🚀 使用步骤

### 1. 访问API管理页面
```
http://localhost:3001/#/admin/data-management/api-management
```

### 2. 找到目标API
- 浏览API接口列表
- 使用筛选器按分类查找
- 查看API详情了解参数说明

### 3. 查看数据
1. 点击操作栏中的 **"查看数据"** 按钮（绿色按钮）
2. 在弹出的对话框中设置查询参数
3. 点击 **"查询数据"** 按钮执行API调用
4. 查看返回的数据结果

### 4. 数据操作
- **表格展示**: 数组数据自动以表格形式展示
- **JSON展示**: 其他格式数据以JSON形式展示
- **数据导出**: 点击"导出数据"按钮下载CSV文件
- **数据限制**: 表格最多显示100条数据，超出部分会有提示

## 🔍 使用示例

### 示例1: 查看股票基础信息
1. 找到"股票列表 (stock_basic)"API
2. 点击"查看数据"
3. 设置参数: `limit = 10`
4. 点击"查询数据"
5. 查看返回的股票列表数据

### 示例2: 查看特定股票行情
1. 找到"日线行情 (daily)"API
2. 点击"查看数据"
3. 设置参数: 
   - `ts_code = 000001.SZ`
   - `start_date = 20240101`
   - `end_date = 20240131`
4. 点击"查询数据"
5. 查看该股票的历史行情数据

## ⚠️ 注意事项

### 数据限制
- 表格展示最多显示100条数据
- 大量数据建议使用导出功能
- API调用受Tushare积分和频率限制

### 参数格式
- 日期格式: `YYYYMMDD` (如: 20240101)
- 股票代码: 包含后缀 (如: 000001.SZ)
- 数值参数: 直接输入数字

### 错误处理
- 参数错误会显示具体错误信息
- 网络错误会有相应提示
- 认证失败请检查登录状态
