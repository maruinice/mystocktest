## 实现内容

### 1. 后端API ✅

#### 创建文件
- `app/api/quote_api.py` - 实时行情API

#### API端点
1. **获取单个股票实时行情**
   - 路径: `GET /api/quote/realtime/<stock_code>`
   - 示例: `/api/quote/realtime/000001`
   - 返回: 实时价格、涨跌幅、成交量等

2. **批量获取实时行情**
   - 路径: `POST /api/quote/realtime/batch`
   - 请求体: `{"codes": ["000001", "600519"]}`
   - 返回: 多个股票的实时行情

3. **健康检查**
   - 路径: `GET /api/quote/health`
   - 返回: 服务状态

### 2. 前端组件 ✅

#### 创建文件
- `stock-ai-frontend/src/components/RealtimeQuote.vue` - 实时行情组件

#### 组件功能
1. **显示实时价格**
   - 当前价
   - 涨跌额
   - 涨跌幅
   - 颜色区分（红涨绿跌）

2. **显示详细信息**
   - 今开、昨收
   - 最高、最低
   - 成交量
   - 更新时间

3. **自动刷新**
   - 支持自动刷新
   - 可配置刷新间隔
   - 默认5秒刷新一次

4. **数据源标识**
   - 显示数据来源（腾讯/东方财富/新浪）
   - 不同数据源不同颜色标签

#### 组件属性
```typescript
interface Props {
  stockCode: string        // 股票代码
  autoRefresh?: boolean    // 是否自动刷新
  refreshInterval?: number // 刷新间隔（毫秒）
}
```

#### 使用示例
```vue
<RealtimeQuote 
  stock-code="000001"
  :auto-refresh="true"
  :refresh-interval="5000"
/>
```

## 技术实现

### 数据流
```
用户选择股票
    ↓
前端组件加载
    ↓
调用 /api/quote/realtime/<code>
    ↓
后端调用 RealtimeQuoteService
    ↓
从腾讯/东方财富/新浪获取数据
    ↓
返回实时行情数据
    ↓
前端显示并自动刷新
```

### 缓存策略
- 后端缓存: 3秒
- 前端刷新: 5秒
- 避免频繁请求

### 错误处理
1. **网络错误**: 显示错误提示
2. **数据源失败**: 自动切换数据源
3. **股票代码错误**: 显示友好提示
