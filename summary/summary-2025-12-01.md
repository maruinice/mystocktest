## 技术细节

### 实时数据源
- 使用新浪财经 HTTP API (`hq.sinajs.cn`) 获取实时行情
- 作为数据库数据的补充，优先使用实时数据

### 真实交易规则实现
1. **T+1制度**:
   - 买入时股票进入 `frozen_quantity`
   - 次日开盘前自动转入 `available_quantity`
   - 卖出时只能卖出可用数量

2. **手续费计算**:
   - 佣金：成交金额 × 0.03%，最低5元
   - 印花税：卖出时收取，成交金额 × 0.1%
   - 过户费：成交金额 × 0.002%（双向）

3. **资金管理**:
   - 下单时冻结资金
   - 成交时根据实际价格和手续费计算差额
   - 撤单时释放冻结资金

### 前端交互
- 利用 Vue Router 的 query 参数在组件间传递操作指令
- 自动加载股票信息并设置交易方向
