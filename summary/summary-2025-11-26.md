## 完成的任务

### 1. 持仓实时价格更新服务 ✅

#### 问题描述
- Dashboard显示持仓市值为 ¥0.00
- 持仓的 `last_price` 字段为0，导致市值和盈亏计算不准确
- 用户无法看到真实的持仓价值和盈亏情况

#### 解决方案
创建了持仓价格更新服务 (`position_price_updater.py`)，实现以下功能：

1. **定时更新机制**
   - 每3秒自动更新一次所有持仓的实时价格
   - 后台线程运行，不影响主服务性能
   - 支持手动触发更新

2. **批量价格获取**
   - 收集所有持仓的股票代码
   - 使用实时行情服务批量获取价格
   - 减少API调用次数，提高效率

3. **自动计算市值和盈亏**
   - 更新 `last_price` 字段
   - 计算 `market_value` = quantity × last_price
   - 计算 `profit_loss` = market_value - cost_basis
   - 计算 `profit_loss_pct` = (profit_loss / cost_basis) × 100

4. **交易时间检测**
   - 支持检测交易时间（周一至周五 9:30-11:30, 13:00-15:00）
   - 可配置是否只在交易时间更新

#### 技术实现

**文件**: `app/services/position_price_updater.py`

**核心代码**:
```python
class PositionPriceUpdater:
    def __init__(self, update_interval: int = 3):
        self.update_interval = update_interval
        self.is_running = False
        
    def start(self):
        """启动更新服务"""
        self.is_running = True
        self.update_thread = threading.Thread(target=self._update_loop, daemon=True)
        self.update_thread.start()
    
    def _update_all_positions(self):
        """更新所有持仓的价格"""
        # 获取所有持仓
        positions = db.query(DBPosition).filter(DBPosition.quantity > 0).all()
        
        # 批量获取实时价格
        stock_codes = [pos.stock_code for pos in positions]
        prices_data = realtime_quote_service.get_batch_realtime_prices(stock_codes)
        
        # 更新每个持仓
        for position in positions:
            current_price = prices_data.get(position.stock_code, {}).get('current', 0)
            position.last_price = Decimal(str(current_price))
            position.market_value = position.quantity * position.last_price
            position.profit_loss = position.market_value - position.cost_basis
            # ...
```
