# 服务管理脚本使用说明

## 📋 脚本列表

项目根目录提供了三个一键管理脚本，方便快速启动、停止和重启整个项目服务。

### 1. `start_all.sh` - 一键启动所有服务

**功能：** 启动整个项目的所有服务，包括：
- Docker Compose 服务（MySQL、Redis、Celery Worker、Celery Beat、Flower）
- Flask API 服务（端口 5000）
- WebSocket 服务（端口 8765）
- 前端 Vue3 服务（端口 5173 或 3000）

**使用方法：**
```bash
cd /home/meiming/source_code/xl_ai_stock_trading
./start_all.sh
```

**执行流程：**
1. 检查系统环境（Docker、Conda、Node.js）
2. 启动 Docker Compose 服务（MySQL、Redis、Celery Worker、Celery Beat、Flower）
3. **初始化并激活 Conda 环境 `stock_trading`**
4. 启动 Flask API 服务（使用 Conda 环境中的 Python）
5. 启动 WebSocket 服务（使用 Conda 环境中的 Python）
6. 检查并启动 Celery 服务（如果 Docker 中未运行，使用 Conda 环境中的 Celery）
7. 启动前端开发服务器

**输出信息：**
- 显示每个服务的启动状态
- 提供所有服务的访问地址
- 显示日志文件位置

---

### 2. `stop_all.sh` - 一键关闭所有服务

**功能：** 停止整个项目的所有服务

**使用方法：**
```bash
cd /home/meiming/source_code/xl_ai_stock_trading
./stop_all.sh
```

**执行流程：**
1. 停止前端服务
2. 停止后端 Python 服务（Flask、WebSocket、Celery）
3. 停止 Docker Compose 服务
4. 清理临时文件（PID 文件）

**特点：**
- 优先通过 PID 文件停止服务
- 如果 PID 文件不存在，通过进程名停止
- 自动清理临时文件

---

### 3. `restart_all.sh` - 一键重启所有服务

**功能：** 先停止所有服务，再启动所有服务

**使用方法：**
```bash
cd /home/meiming/source_code/xl_ai_stock_trading
./restart_all.sh
```

**执行流程：**
1. 调用 `stop_all.sh` 停止所有服务
2. 等待 5 秒确保服务完全停止
3. 调用 `start_all.sh` 启动所有服务

## 🌐 服务访问地址

启动成功后，可以通过以下地址访问各个服务：

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端应用 | http://localhost:5173 或 http://localhost:3000 | Vue3 前端界面 |
| Flask API | http://localhost:5000 | 后端 API 服务 |
| API 文档 | http://localhost:5000/apidocs/ | API 接口文档 |
| WebSocket | ws://localhost:8765 | WebSocket 实时通信 |
| Flower 监控 | http://localhost:5555 | Celery 任务监控 |
| MySQL | localhost:3306 | 数据库服务 |
| Redis | localhost:6379 | 缓存服务 |

```bash

tail -f stock_ai_trading/flask.log

# 查看前端日志
tail -f stock-ai-frontend/frontend.log

# 查看所有日志
tail -f stock_ai_trading/*.log stock-ai-frontend/frontend.log
```

## ⚙️ 环境要求

使用这些脚本前，请确保系统已安装：

1. **Docker** 和 **docker compose**
   ```bash
   docker --version
   docker compose version
   ```

2. **Conda**（Miniconda 或 Anaconda）
   ```bash
   conda --version
   ```

3. **Node.js** 和 **npm**
   ```bash
   node --version
   npm --version
   ```

4. **Conda 环境** `stock_trading` 已创建并配置
   ```bash
   # 检查环境是否存在
   conda env list
   
   # 如果不存在，创建环境
   conda create -n stock_trading python=3.10 -y
   conda activate stock_trading
   
   # 安装项目依赖
   cd stock_ai_trading
   pip install -r requirements.txt
   ```
   
   **重要提示：** 脚本会自动激活 Conda 环境 `stock_trading`，所有 Python 服务（Flask、WebSocket、Celery）都会使用该环境中的 Python 和依赖包。

## 🔧 常见问题

### 1. 端口被占用

如果启动时提示端口被占用，脚本会自动尝试停止占用端口的进程。如果自动停止失败，可以手动停止：

```bash
# 查看端口占用
sudo lsof -i :5000
sudo lsof -i :5173

# 停止占用端口的进程
kill -9 <PID>
```

### 2. Conda 环境未激活或初始化失败

脚本会自动尝试多种方式初始化 Conda：
- 从 `$HOME/miniconda3/etc/profile.d/conda.sh`
- 从 `$HOME/anaconda3/etc/profile.d/conda.sh`
- 从 `/opt/conda/etc/profile.d/conda.sh`
- 使用 `conda shell.bash hook`

如果自动初始化失败，可以手动激活：

```bash
# 方式1：使用 source（推荐）
source $HOME/miniconda3/etc/profile.d/conda.sh
conda activate stock_trading

# 方式2：使用 eval hook
eval "$(conda shell.bash hook)"
conda activate stock_trading
```

**确保 Conda 环境存在：**
```bash
# 检查环境是否存在
conda env list

# 如果不存在，创建环境
conda create -n stock_trading python=3.10 -y
conda activate stock_trading
pip install -r stock_ai_trading/requirements.txt
```

### 3. Docker 服务启动失败

检查 Docker 是否运行：
```bash
docker info
```

如果 Docker 未运行，启动 Docker：
```bash
sudo systemctl start docker
```

### 4. 前端依赖未安装

如果前端启动失败，可能需要先安装依赖：

```bash
cd stock-ai-frontend
npm install
```

## 💡 使用建议

1. **开发调试时：**
   - 使用 `start_all.sh` 启动所有服务
   - 使用 `stop_all.sh` 停止服务
   - 使用 `restart_all.sh` 快速重启

2. **查看服务状态：**
   ```bash
   # 查看 Docker 服务状态
   cd stock_ai_trading
   docker compose ps
   
   # 查看进程状态
   ps aux | grep -E "(flask|celery|node)"
   ```

3. **单独启动某个服务：**
   - 如果只需要启动某个服务，可以查看脚本内容，提取对应的命令单独执行
