# 实时行情服务使用说明

## 概述

实时行情服务提供了免费获取A股实时行情数据的功能，支持多个数据源自动切换，确保数据获取的稳定性。

## 数据源

### 1. 腾讯财经（主要数据源）⭐⭐⭐⭐⭐
- **接口**: `http://qt.gtimg.cn/q=`
- **优点**: 稳定、快速、数据准确
- **延迟**: 约3秒
- **限制**: 无

### 2. 东方财富（备用数据源）⭐⭐⭐⭐
- **接口**: `http://push2.eastmoney.com/api/qt/stock/get`
- **优点**: 数据全面、支持JSON格式
- **延迟**: 约3秒
- **限制**: 无

### 3. 新浪财经（备用数据源）⭐⭐⭐⭐
- **接口**: `http://hq.sinajs.cn/list=`
- **优点**: 历史悠久、数据稳定
- **延迟**: 约3秒
- **限制**: 需要设置User-Agent

## 使用方法

### 基本用法

```python
from app.services.realtime_quote_service import realtime_quote_service

# 获取单个股票的实时行情
data = realtime_quote_service.get_realtime_price('000001')

if data:
    print(f"股票名称: {data['name']}")
    print(f"当前价格: ¥{data['current']:.2f}")
    print(f"涨跌幅: {data['change_pct']:.2f}%")
```

### 批量获取

```python
# 批量获取多个股票的实时行情
codes = ['000001', '600519', '600036']
batch_data = realtime_quote_service.get_batch_realtime_prices(codes)

for code, data in batch_data.items():
    print(f"{code} ({data['name']}): ¥{data['current']:.2f}")
```

订单撮合服务已自动集成实时行情服务，无需额外配置：

```python
from app.services.order_matching_service import order_matching_service
```

## 特性

### 1. 自动切换数据源
当一个数据源失败时，自动切换到下一个数据源，确保数据获取的稳定性。

### 2. 智能缓存
- 缓存时间：3秒
- 避免频繁请求同一股票
- 提高响应速度

### 3. 错误处理
- 自动重试
- 详细的错误日志
- 优雅降级


### 超时设置
所有请求默认超时时间为5秒，可以根据网络情况调整。

## 注意事项

### 1. 交易时间
实时行情数据仅在交易时间内更新：
- **交易时间**: 周一至周五 9:30-11:30, 13:00-15:00
- **非交易时间**: 返回最后一次交易的收盘价

### 2. 股票代码格式
- **上海股票**: 以6开头，如 `600519`（茅台）
- **深圳股票**: 以0或3开头，如 `000001`（平安银行）、`300750`（宁德时代）

### 3. 数据延迟
- 实时行情有约3秒延迟
- 不适合高频交易
- 适合Paper交易和模拟交易

### 4. 请求频率
建议：
- 单个股票：不超过1次/秒
- 批量请求：不超过10个股票/次
- 使用缓存减少请求

## 故障排查

### 问题1: 所有数据源都无法获取行情

**可能原因**:
- 网络连接问题
- 股票代码错误
- 服务器限制

**解决方案**:
```bash
# 测试网络连接
curl http://qt.gtimg.cn/q=sz000001

# 检查股票代码格式
# 正确: '000001', '600519'
# 错误: '000001.SZ', 'SZ000001'
```

### 问题2: 返回价格为0

**可能原因**:
- 非交易时间
- 股票停牌
- 新股未开盘

**解决方案**:
- 检查当前时间是否在交易时间内
- 查看股票是否停牌
- 使用历史数据作为备选

### 问题3: 请求超时

**可能原因**:
- 网络延迟
- 数据源服务器繁忙

**解决方案**:
```python
# 增加超时时间
service = RealtimeQuoteService()
# 修改源码中的timeout参数
```

```python
import redis

class RealtimeQuoteServiceWithRedis(RealtimeQuoteService):
    def __init__(self):
        super().__init__()
        self.redis_client = redis.Redis(host='localhost', port=6379)
    
    def get_realtime_price(self, stock_code: str):

        cached = self.redis_client.get(f'quote:{stock_code}')

            return json.loads(cached)
```
