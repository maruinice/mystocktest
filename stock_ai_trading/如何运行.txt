================================================================
如何运行数据同步
================================================================

问题：运行批处理文件报错

原因：特殊字符导致cmd无法识别

解决：使用以下任一方法

================================================================
方法1：使用新的简化脚本（推荐）
================================================================

双击运行：sync_now.bat

这个脚本：
- 没有特殊字符
- 自动同步所有数据
- 自动检查结果
- 简单可靠

================================================================
方法2：直接运行Python脚本
================================================================

打开命令行（cmd），然后：

cd d:\code\AIgogogo\stock_ai_trading

python force_sync.py

python check_data.py

================================================================
方法3：在PowerShell中运行
================================================================

打开PowerShell，然后：

cd d:\code\AIgogogo\stock_ai_trading

python force_sync.py

python check_data.py

================================================================
方法4：使用修复后的批处理
================================================================

双击运行：auto_sync.bat

（已经修复了特殊字符问题）

================================================================
推荐顺序
================================================================

1. 最简单：双击 sync_now.bat

2. 如果不行：打开cmd，运行
   cd d:\code\AIgogogo\stock_ai_trading
   python force_sync.py

3. 查看结果：
   python check_data.py

================================================================
预期结果
================================================================

同步成功后会显示：

表: industry_classification
记录数: 31
样例数据:
  1. {'industry_code': '801010.SI', 'industry_name': '农林牧渔'}

如果还是报错
================================================================

1. 确认Python已安装
   python --version

2. 确认在正确的目录
   cd d:\code\AIgogogo\stock_ai_trading

3. 确认Tushare Token已配置
   检查 .env 文件

4. 查看详细错误
   logs\flask_api.log
