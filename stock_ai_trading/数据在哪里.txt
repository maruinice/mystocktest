========================================
  数据在哪里？快速查找指南
========================================

问题：点击同步按钮后，数据库中找不到数据

========================================
  立即执行（3个命令）
========================================

1. 检查数据
   python check_data.py

2. 强制同步
   python force_sync.py

3. 再次检查
   python check_data.py


========================================
  或者使用一键脚本
========================================

fix_no_data.bat

这个脚本会自动：
- 检查当前数据状态
- 询问是否同步
- 强制同步数据
- 再次检查结果

========================================
  可能的原因
========================================

原因1: 表不存在
--------------
症状: check_data.py显示"表不存在"
解决: 运行数据库迁移
      alembic upgrade head


原因2: 表是空的
--------------
症状: check_data.py显示"表是空的"或"记录数: 0"
解决: 运行强制同步
      python force_sync.py


原因3: 同步接口没被调用
--------------------
症状: 点击前端按钮没反应
解决: 
  1. 检查后端是否运行
  2. 检查浏览器控制台错误
  3. 检查后端日志 logs/flask_api.log


原因4: Tushare API失败
--------------------
症状: 同步返回成功但无数据
可能原因:
  - Token无效或未配置
  - 积分不足
  - 非交易日（周末、节假日）

检查Token:
  python -c "from app.config.settings import settings; print(settings.TUSHARE_TOKEN)"

========================================
  重要提示
========================================

1. 行业分类数据最容易成功
   - 数据量小（31条）
   - 不受交易日限制
   - 建议先测试这个

2. 涨跌停和停复牌数据
   - 只有交易日才有数据
   - 周末和节假日为空是正常的
   - 首次同步建议只同步1天

3. 查看详细日志
   - 位置: logs/flask_api.log
   - 所有错误都会记录在这里

4. Tushare积分要求
   - 行业分类: 2000积分
   - 涨跌停价格: 2000积分
   - 停复牌信息: 120积分
   - 审计意见: 500积分
