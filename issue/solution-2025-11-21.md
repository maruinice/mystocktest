# 问题与解决方法记录 - 2025-11-21

## 问题1：策略管理中心"创建策略"按钮无法点击

**时间**：2025-11-21 11:00:00

**问题描述**：
- 在"首页/策略管理"页面中，点击"创建策略"按钮无响应
- 点击后其他菜单项也变得无响应
- 浏览器控制台无相关错误日志

**原因分析**：
1. 按钮的 `@click` 事件处理器使用了 `.stop.prevent` 修饰符，可能阻止了默认行为
2. 对话框的 `v-model` 绑定方式不正确，使用了 `:model-value` 和 `@update:model-value` 而非 `v-model`
3. `StrategyBuilder` 组件在渲染时出现 `Cannot read properties of undefined (reading 'period')` 错误，导致对话框无法显示

**解决方法**：
1. 移除按钮上的 `.stop.prevent` 修饰符，改为直接使用 `@click="handleCreateStrategy"`
2. 将对话框绑定从 `:model-value` 改为 `v-model="showStrategyBuilder"`
3. 在 `StrategyBuilder.vue` 模板中添加安全检查，确保 `indicatorParams[indicator.code]` 存在后再访问其属性
4. 增强 `initIndicatorParams` 函数，添加错误处理和更严格的参数初始化检查
5. 在 `onMounted` 生命周期中添加额外的验证逻辑，确保所有选中的指标参数都已正确初始化

**相关文件**：
- `stock-ai-frontend/src/views/strategy/Strategy.vue`
- `stock-ai-frontend/src/views/strategy/components/StrategyBuilder.vue`

## 问题2：WebSocket 连接无限重连导致控制台错误日志过多

**时间**：2025-11-21 11:15:00

**问题描述**：
- WebSocket 连接因 token 验证失败（4002 Invalid token）而关闭
- 前端不断尝试重连，导致控制台出现大量错误日志
- 影响用户体验和系统性能

**原因分析**：
- WebSocket 客户端在遇到认证错误（4001, 4002, 4003）时仍然尝试重连
- 没有区分认证错误和网络错误，导致无限重连循环

**解决方法**：
1. 在 `onclose` 事件处理中添加逻辑，当遇到认证错误（4001, 4002, 4003）时停止重连
2. 添加 token 检查逻辑，验证 token 是否存在、是否过期、格式是否正确
3. 即使 token 有效但认证失败，也停止重连以避免无限循环

**相关文件**：
- `stock-ai-frontend/src/utils/websocket.ts`

## 问题3：Element Plus 图标组件未解析错误

**时间**：2025-11-21 11:30:00

**问题描述**：
- 控制台出现 `Failed to resolve component: VideoStop` 警告
- 控制台出现 `Failed to resolve component: Magic` 错误
- 图标无法正常显示

**原因分析**：
1. `VideoStop`、`VideoPause` 图标在模板中嵌套使用 `<el-icon>` 标签，导致组件解析失败
2. Element Plus 图标库中没有 `Magic` 图标，只有 `MagicStick` 图标
3. 部分图标（如 `View`、`DataAnalysis`、`CopyDocument`、`Clock`、`Download`）未在 `main.ts` 中注册

**解决方法**：
1. 修复 `VideoStop`、`VideoPause` 图标的使用方式，移除嵌套的 `<el-icon>` 标签
2. 在 `main.ts` 中将 `Magic` 注册为 `MagicStick` 的别名
3. 添加缺失的图标到注册列表：`View`、`DataAnalysis`、`CopyDocument`、`Clock`、`Download`

**相关文件**：
- `stock-ai-frontend/src/main.ts`
- `stock-ai-frontend/src/views/strategy/Strategy.vue`

## 问题4：资源预加载警告

**时间**：2025-11-21 11:35:00

**问题描述**：
- 浏览器控制台出现资源预加载警告：
  - `The resource http://localhost:3000/src/main.ts was preloaded using link preload but not used within a few seconds`
  - `The resource http://localhost:3000/src/styles/index.scss was preloaded using link preload but not used within a few seconds`
  - `The resource http://at.alicdn.com/t/font_2305433_bu8s0ulpz6.woff2 was preloaded using link preload but not used within a few seconds`

**原因分析**：
- 在 `index.html` 中使用了 `<link rel="preload">` 预加载资源
- Vite 开发模式下，这些预加载可能不会在预期时间内使用，导致浏览器警告

**解决方法**：
- 注释掉 `index.html` 中的资源预加载链接，避免在开发模式下产生警告
- 这些预加载在生产环境中可能仍然有用，可以根据需要启用

**相关文件**：
- `stock-ai-frontend/index.html`
